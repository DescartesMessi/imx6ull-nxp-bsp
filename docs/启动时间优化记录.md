# 启动时间优化记录

更新时间：2026-09-29

本文记录 U-Boot 与 Linux 内核启动时间优化的目标、修改内容、验证结果和回退方法。

## 1. 优化目标

- 在保持现有启动方式的前提下缩短启动时间。
- 保留串口日志输出。
- 保留网络功能，开发调试仍可使用 TFTP/NFS。
- 保留 U-Boot 3 秒 `bootdelay`。
- 保留 SD 卡与 eMMC 启动能力。
- 保留现有板级驱动功能。

## 2. U-Boot 裁剪

### 2.1 修改文件

- `sources/uboot-imx/include/configs/mx6ull_alientek_jjl.h`

### 2.2 裁剪内容

删除以下配置块：

- Video/Logo
  - `CONFIG_VIDEO`
  - `CONFIG_CFB_CONSOLE`
  - `CONFIG_VIDEO_MXS`
  - `CONFIG_VIDEO_LOGO`
  - `CONFIG_SPLASH_SCREEN`
  - `CONFIG_CMD_BMP`
  - `CONFIG_VIDEO_BMP_RLE8/LOGO`
- USB Host / USB 存储 / USB 网卡
  - `CONFIG_CMD_USB`
  - `CONFIG_USB_EHCI`
  - `CONFIG_USB_EHCI_MX6`
  - `CONFIG_USB_STORAGE`
  - `CONFIG_USB_HOST_ETHER`
  - `CONFIG_USB_ETHER_ASIX`
- QSPI / SPI NOR
  - `CONFIG_FSL_QSPI`
  - `CONFIG_CMD_SF`
  - `CONFIG_SPI_FLASH`
  - `CONFIG_SPI_FLASH_BAR`
  - `CONFIG_SPI_FLASH_STMICRO`
  - `CONFIG_SF_DEFAULT_*`
  - `CONFIG_QSPI_*`

### 2.3 保留内容

- 串口：`CONFIG_MXC_UART`
- 网络：`CONFIG_CMD_NET`、`CONFIG_FEC_MXC`、`CONFIG_PHYLIB`、DHCP/PING/MII/NFS/TFTP
- MMC/SD/eMMC：MMC、ESDHC、FAT、环境变量存 MMC、`bootz`
- I2C/PMIC、GPIO 命令
- `bootdelay` 保持 3 秒

### 2.4 效果

- `u-boot.imx` 约 `415KB` 降至 `303KB`。
- 启动日志中不再出现 `unsupported panel TFT7016`。
- 串口、MMC、网络初始化保持正常。

## 3. Linux 内核优化

### 3.1 修改文件

- `sources/linux-imx/arch/arm/configs/imx6ull_alientek_jjl_defconfig`
- `sources/linux-imx/arch/arm/boot/dts/imx6ull-alientek-jjl.dts`
- `scripts/create_rootfs.sh`
- `deploy/nfs/rootfs/etc/init.d/rcS`

### 3.2 内核配置精简

关闭以下配置：

- `CONFIG_BLK_DEV_INITRD`
- `CONFIG_KALLSYMS_ALL`
- `CONFIG_PERF_EVENTS`
- `CONFIG_MODULE_SRCVERSION_ALL`
- `CONFIG_PM_DEBUG`
- `CONFIG_PM_TEST_SUSPEND`
- `CONFIG_IP_PNP_DHCP`，保留 `CONFIG_IP_PNP`
- `CONFIG_FRAMEBUFFER_CONSOLE`
- `CONFIG_FRAMEBUFFER_CONSOLE_DETECT_PRIMARY`
- `CONFIG_LOGO`
- `CONFIG_DEBUG_FS`
- `CONFIG_MAGIC_SYSRQ`
- `CONFIG_FONTS`
- `CONFIG_FONT_8x8`
- `CONFIG_FONT_8x16`

保留串口、网络、NFS root、MMC 和全部板级驱动。

### 3.3 设备树优化

- 将 `&qspi` 改为 `status = "disabled"`，避免无 QSPI Flash 时的无效 probe。

### 3.4 rootfs 初始化优化

- 去掉 `rcS` 中的 `mdev -s` 冷插拔扫描。
- 保留 `mount proc/sysfs` 和 mdev hotplug。
- devtmpfs 已由内核自动挂载，设备节点不受影响。

## 4. 启动时间测量

通过串口时间戳日志测量：

- U-Boot 阶段：`U-Boot banner` 到 `Starting kernel` 约 `3.86s`，其中 3 秒为 `bootdelay`。
- 内核阶段：`Starting kernel` 到控制台就绪
  - 优化前：约 `9.85s`
  - 优化后：约 `8.58s`
  - 节省约 `1.27s`
- 整机启动仍主要受 3 秒 `bootdelay` 和 NFS 网络启动影响。

## 5. 构建与部署

### 5.1 编译

```bash
bash scripts/build_uboot.sh
bash scripts/build_kernel.sh
```

### 5.2 部署位置

- U-Boot：
  - `deploy/tftp/u-boot.bin`
  - `deploy/tftp/u-boot.imx`
  - SD 卡、eMMC `boot0`、eMMC 用户区，起始扇区 2
- 内核：
  - `deploy/tftp/zImage`
  - `deploy/tftp/imx6ull-alientek-jjl.dtb`
  - eMMC FAT 分区 `zImage`
  - eMMC FAT 分区启动文件名 `imx6ull-alientej-jjl.dtb`

说明：当前板子实际从 eMMC FAT 分区加载内核，不是从 TFTP 加载。

## 6. 功能验证

新镜像启动后确认：

- 串口日志正常。
- `eth0` 正常获取 IP。
- NFS rootfs 正常挂载。
- SD/eMMC 正常识别。
- 设备节点正常：
  - `video0`、`video1`、`fb0`
  - `i2c-0`、`i2c-1`
  - `snd`、`rtc0`、`watchdog0`
  - `mmcblk1p1`、`mmcblk1p2`
  - `ap3216c`、`beep_device`、`dht11`、`icm20608`、`sr04`、`sr501`
- 摄像头、触摸屏、音频、传感器驱动均正常加载。

## 7. 回退方法

### 7.1 U-Boot 回退

更新前备份：

- `deploy/nfs/rootfs/old_boot0.img`
- `deploy/nfs/rootfs/old_user.img`

如需回退，可将备份写回原位置，或重新编译修改前的 U-Boot。

### 7.2 内核回退

- 回退 `imx6ull_alientek_jjl_defconfig` 和 DTS 的修改后重新编译。
- 将旧 `zImage` 和 `dtb` 重新写入 eMMC FAT 分区。

## 8. 后续可优化方向

- 去掉或缩短 3 秒 `bootdelay`。
- 将根文件系统从 NFS 改为 eMMC ext4，减少网络协商和 NFS 挂载时间。
- 进一步将非启动必需的板级驱动改为模块并按需加载。
- 精简 DTS 中未使用的外设节点。
